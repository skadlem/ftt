Create an implementation plan for a browser extension that helps knowledge workers save, restore, and share tab sessions as project workspaces. Context: users juggle research tabs across Chrome and Edge, and our current extension can save window tabs to local JSON but loses authentication state expectations, pinned tabs, and container separation. Goal: build a reliable workspace manager with named collections, automatic snapshotting, duplicate detection, notes per workspace, and export/import in a portable format. Constraints: must not store sensitive page content or cookies, must respect incognito restrictions, must operate under Manifest V3 service worker limits, must handle tab discards gracefully, and must sync metadata only through optional user-connected storage. Existing assets: a prototype sidebar UI, tab capture permissions, IndexedDB layer, and a minimal restore flow that opens URLs sequentially. Plan should include data schema, conflict handling for restored tabs, performance budget for large windows, permission rationale, UX for accidental closure recovery, test scenarios, and migration from current JSON format.
