Draft a practical plan for a browser extension that supports accessibility reviewers by surfacing semantic and readability issues on live web pages. Context: our accessibility consultancy needs an internal extension for audits, not a general consumer product. We have a Chrome extension that injects a panel with color-contrast checks, but it fails on SPAs, shadow DOM components, and dynamically loaded dialogs. Goal: extend it to annotate landmarks, heading order, missing form labels, low-contrast text, language attributes, and focus visibility problems, while allowing reviewers to capture evidence as structured reports. Constraints: must not send page content to external services, must run on-demand to avoid performance penalties, must support keyboard-only operation, must generate WCAG-oriented summaries, and must work in Chromium with a possible later Firefox port. What exists already: content script, Axe-core integration started but not maintained, options page, screenshot capture behind a permission, and sample audit templates. Provide a plan for modular rule adapters, mutation observation strategy, evidence storage, false-positive triage, report export formats, and acceptance tests using representative public sites.
